## LCP element

The LCP element is the `<h1>` in the hero section. It renders after the
stylesheet loads (17.8 KB, no render-blocking fonts, no web font requests).
The hero logo (`logo.webp`) is preloaded with `<link rel="preload">`.

No render-blocking resources: the only `<link>` in the critical path is the
stylesheet itself. No web fonts are loaded — the site uses the system font
stack with Inter as the preferred face if available.

## Optimizations applied

1. **Images:** Source PNGs (1034 KB + 1560 KB) downscaled and converted to
   WebP (55.6 KB + 130.0 KB) — a 97% reduction. Generated by
   `tools/optimize_images.py`.
2. **No web fonts:** System font stack eliminates the FOIT/FOUT and the
   network round-trip entirely.
3. **Zero framework JS:** 5.6 KB of vanilla JS vs 40–150 KB for a typical
   framework runtime.
4. **Single CSS file:** No CSS-in-JS, no utility framework, no unused styles.
5. **Lazy loading:** Below-fold images use `loading="lazy"` and
   `decoding="async"`.
6. **No tracking libraries:** Zero third-party requests on any page.

## Source images

The original PNGs (`logo.png`, `team.png`) remain in `assets/img/` for
reference. They are not referenced by any page. Regenerate WebP assets with:

```bash
# requires Pillow (pip install Pillow)
python tools/optimize_images.py
```
